# 🍔 FoodConnect

FoodConnect is a Flutter application designed for surplus food distribution, real-time donor/volunteer coordination, and community food rescue.

---

## ⚡ Quick Start on a New Laptop (Windows & macOS)

For full details on prerequisites, SDKs, and environment configurations, read the [REQUIREMENTS.md](file:///Users/apple/Codes/foodconnect/REQUIREMENTS.md).

### 🍎 On macOS:
```bash
# 1. Run automated setup (checks tools, installs Flutter & CocoaPods & Functions dependencies)
./scripts/setup.sh

# 2. Run the application
./scripts/run_app.sh
# or directly:
flutter run
```

### 🪟 On Windows:
```cmd
:: 1. Run automated setup (in Command Prompt)
.\scripts\setup.bat

:: OR in PowerShell:
.\scripts\setup.ps1

:: 2. Run the application
.\scripts\run_app.bat
:: or directly:
flutter run
```

---

## 📋 System Requirements Summary

- **Flutter SDK**: 3.29+ (Dart `^3.11.5`)
- **Java**: JDK 17 or JDK 21
- **Android SDK**: API 34/35 & Command-line Tools
- **Node.js**: v18 / v20 LTS & npm (for Cloud Functions in `/functions`)
- **Firebase CLI**: `npm install -g firebase-tools`
- **macOS only**: Xcode 15+ & CocoaPods (`brew install cocoapods` or `gem install cocoapods`)
- **Windows only**: Visual Studio C++ build tools (optional, for Windows desktop target)
